# 📘 درس ۲-۴: ساخت جدول آخرین فاکتورها (RecentInvoices.jsx)

<div dir="rtl">

سلام! به چهارمین گام از **فاز ۲ (پیشخوان جامع فریلنسر)** خوش آمدی.  
در این درس یاد می‌گیریم که چطور یک **جدول داده (Data Table)** حرفه‌ای و تعاملی با استایل نئوبروتال، متن فارسی و ارقام مالی تومانی را با جاوااسکریپت خالص بسازیم.

---

### ۱. هدف و جایگاه این کامپوننت در داشبورد:
در هر نرم‌افزار مالی، جدول فاکتورها **مرکزی‌ترین عنصر اطلاعاتی** است. فریلنسر باید در یک نگاه بفهمد:
- چه فاکتورهایی اخیراً صادر شده؟
- کدام‌ها تسویه شده و کدام‌ها هنوز معلق‌اند؟
- آیا فاکتور معوقه‌ای وجود دارد که نیاز به پیگیری فوری داشته باشد؟

### ۳. نکات آموزشی و فنی مهم:

#### الف) دکمه‌های عملیات هوشمند (Conditional Rendering):
بر اساس وضعیت هر فاکتور، دکمه‌های متفاوتی نمایش داده می‌شود. این کار با `switch/case` داخل یک تابع `renderActions` انجام شد:

```jsx
const renderActions = (invoice) => {
  switch (invoice.status) {
    case 'paid':
      return (
        <>
          <ActionButton title="مشاهده فاکتور">👁</ActionButton>
          <ActionButton title="دانلود PDF">📥</ActionButton>
        </>
      );
    case 'pending':
      return (
        <>
          <ActionButton title="ثبت پرداخت" variant="mint">✓</ActionButton>
          <ActionButton title="مشاهده جزئیات">👁</ActionButton>
        </>
      );
    case 'overdue':
      return (
        <Button size="sm" variant="default">🔔 یادآوری</Button>
      );
    case 'draft':
      return (
        <>
          <ActionButton title="ویرایش پیش‌نویس">✏️</ActionButton>
          <ActionButton title="حذف پیش‌نویس">🗑️</ActionButton>
        </>
      );
  }
};
```

#### ب) اسکرول افقی ریسپانسیو در موبایل:
جدول دارای عرض حداقل `min-w-[700px]` است. در گوشی موبایل، این جدول به صورت افقی قابل اسکرول می‌شود (`overflow-x-auto`) بدون اینکه چینش بدنه صفحه به هم بریزد.

#### ج) تاریخ‌های شمسی قرمزرنگ برای معوقه‌ها:
فاکتورهایی که معوقه (`overdue`) هستند، ستون تاریخ سررسید‌شان با رنگ قرمز مرجانی (`text-retro-coral`) نمایش داده می‌شود تا توجه فوری فریلنسر جلب شود.

#### د) استفاده مجدد از Badge.jsx:
ستون وضعیت از همان کامپوننت نشان کپسولی (`Badge.jsx`) که در فاز ۱ ساختیم استفاده می‌کند. فقط `variant` و `children` مناسب به آن ارسال می‌شود.

### ۴. داده‌های نمونه فارسی (۵ شرکت ایرانی):
برای اینکه داشبورد واقعی به نظر برسد، از نام شرکت‌های معروف ایرانی استفاده کردیم:
1. **اسنپ‌پی فین‌تک** — بازطراحی اپلیکیشن موبایل (۳۲ میلیون تومان، تسویه شده ✅)
2. **دیجی‌کالا مارکت‌پلیس** — دیزاین سیستم و توکن‌ها (۴۵ میلیون، در انتظار ⏳)
3. **کافه بازار** — هویت برند و گایدلاین (۱۸.۵ میلیون، معوقه ❌)
4. **موتور جستجوی ترب** — داشبورد آنالیتیکس (۲۲ میلیون، پیش‌نویس 📝)
5. **دیوار آگهی‌ها** — اسپرینت طراحی فصل اول (۱۶ میلیون، تسویه شده ✅)

### ۵. پانوشت جدول (Table Footer):
در پایین جدول دو عنصر قرار دارد:
- **شمارنده:** نمایش `۵ از ۴۲ فاکتور ثبت‌شده` با فونت مونو.
- **دکمه «مشاهده تمام فاکتورها»:** این دکمه با استایل نئوبروتال و افکت کلیک (`neo-press`) طراحی شده و در فاز ۳ به صفحه فهرست فاکتورها لینک خواهد شد.
