### ۱. فایل `tailwind.config.js` چیست و چه کار می‌کند؟
این فایل مثل **دفترچه قوانین شخصی‌سازی تیلویند** است. تیلویند به صورت پیش‌فرض رنگ‌هایی مثل `bg-blue-500` یا `bg-red-500` دارد، اما ما برای اینکه پروژه‌مان دقیقاً شبیه طرح‌های **Google Stitch** شود، رنگ‌ها و سایه‌های اختصاصی خودمان را در بخش `theme.extend` اضافه کردیم.

#### الف) تعریف رنگ‌های اختصاصی:
در کانفیگ نوشتیم:
```js
colors: {
  canvas: "#FDFBF7",
  retro: {
    yellow: "#FFE600",
    mint: "#A8F0D0",
    lavender: "#C4B5FD",
    coral: "#FF708A",
    tangerine: "#FFB347",
  }
}
```
حالا در هر کامپوننت ری‌اکت بنویسی:
* `bg-retro-yellow` ⬅️ تیلویند رنگ زرد موزی را اعمال می‌کند.
* `bg-retro-mint` ⬅️ تیلویند رنگ سبز نعنایی را اعمال می‌کند.
* `bg-canvas` ⬅️ رنگ کرم ملایم پس‌زمینه را اعمال می‌کند.

### ۲. سایه‌های سخت نئوبروتال (Hard Box Shadows):
در وب‌سایت‌های عادی سایه‌ها تار (Blur) هستند، مثلاً:
```css
/* سایه معمولی و محو شده */
box-shadow: 0px 4px 10px rgba(0, 0, 0, 0.15);
```
اما در سبک **نئوبروتالیسم (Retro Neo-Brutalism)**، سایه تار نمی‌شود؛ بلکه یک کادر مشکی توپر با جابجایی دقیق ۲ یا ۴ پیکسلی است:
```js
boxShadow: {
  'retro-sm': '2px 2px 0px 0px #000000',
  'retro': '4px 4px 0px 0px #000000',
  'retro-lg': '6px 6px 0px 0px #000000',
}
```
* وقتی کلاس `shadow-retro` را به یک کادر می‌دهی، انگار المنت از صفحه کنده شده و ۴ پیکسل روی صفحه سایه انداخته است!

---

### ۳. افکت دکمه فیزیکی و فشردنی (`.neo-press` در `src/index.css`):
یکی از جذاب‌ترین تکنیک‌های این سبک، ایجاد حس کلیک روی دکمه‌های اسباب‌بازی یا کیبوردهای مکانیکی است:
```css
.neo-press:active {
  transform: translate(2px, 2px);
  box-shadow: 1px 1px 0px 0px #000000 !important;
}
```
* **توضیح:** وقتی کاربر روی دکمه کلیک می‌کند (`:active`)، دکمه ۲ پیکسل به پایین و راست هل داده می‌شود و سایه‌اش کم می‌شود؛ دقیقاً مثل این است که دکمه فیزیکی به داخل فرورفته است!
