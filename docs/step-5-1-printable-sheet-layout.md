## ۱. هدف و فلسفه گام ۵-۱

هدف فاز ۵ خلق یک **سند رسمی صورت‌حساب مالیاتی قابل چاپ (Printable Tax Invoice Sheet)** منطبق بر استاندارد بین‌المللی A4 (ISO 216) و ضوابط صدور فاکتورهای شرکتی است.

در این گام:
1. **نوار ابزار هوشمند بالای صفحه (Top Non-Printing Toolbar):**
   - برچسب `print:hidden` برای ناپدید شدن خودکار هنگام پرینت یا ذخیره PDF.
   - دکمه بازگشت نرم به جدول یا فرم صدور فاکتور.
   - بج وضعیت فاکتور (تسویه شده • معتبر / در انتظار پرداخت) همراه با انیمیشن پالس.
   - **موتور زوم زنده و مقیاس بوم:** قابلیت بزرگ‌نمایی (+۱۰٪ تا ۱۴۰٪) و کوچک‌نمایی (-۱۰٪ تا ۷۰٪) به همراه کلید بازنشانی `Fit` روی ۱۰۰٪ با ترنسفورم CSS و نقطه اتکای مرکز-بالا (`transformOrigin: 'top center'`).
   - دکمه «ارسال مستقیم» جهت شبیه‌سازی ارسال نسخه دیجیتال و ایمیل به دپارتمان مالیاتی کارفرما.
   - دکمه پرینت آنی و خروجی PDF با فراخوانی تابع استاندارد مرورگر `window.print()`.

2. **بوم استاندارد A4 (A4 Document Canvas):**
   - در حالت نمایشگر دسکتاپ: یک صفحه سفید متمرکز با حداکثر عرض ۸۶۰ پیکسل، حاشیه ۳ پیکسلی مشکی و سایه سخت ۸ پیکسلی نئوبروتال (`shadow-[8px_8px_0_0_#000000]`).
   - در حالت چاپ (`@media print`):
     ```css
     @page {
       size: A4 portrait;
       margin: 8mm;
     }
     body {
       direction: rtl;
       background: white !important;
       color: black !important;
       -webkit-print-color-adjust: exact !important;
       print-color-adjust: exact !important;
     }
     ```
     حذف کامل سایه‌ها و کادر‌های اضافه برای پرینت دقیق روی برگه کاغذ بدون بریدگی هدر یا فوتر.

3. **مسیرهای اختصاصی در React Router v6:**
   - مسیر `/invoices/print`: پیش‌نمایش چاپی فاکتور در حال تدوین در فرم سازنده فاکتور.
   - مسیر `/invoices/:id/print`: واکشی اطلاعات هر فاکتور دلخواه از جدول فاکتورها با کلیک روی آیکون چشم (👁) و نمایش سند چاپی رسمی آن.

## ۲. توابع و کدهای کلیدی

استفاده از ترنسفورم بهینه بدون افت کیفیت فونت‌ها و بردارها:

```jsx
<div
  id="invoiceCanvas"
  style={{
    transform: zoom !== 100 ? `scale(${zoom / 100})` : 'none',
    transformOrigin: 'top center',
  }}
  className="w-full max-w-[860px] bg-white border-[3px] border-black shadow-[8px_8px_0_0_#000000] print:shadow-none print:border-none print:max-w-none print:w-full p-6 sm:p-10 transition-transform origin-top flex flex-col justify-between"
>
```

اتصال آیکون مشاهده جدول به روت چاپی در `App.jsx`:

```jsx
onViewInvoice={(inv) => navigate(`/invoices/${inv.id}/print`)}
```
