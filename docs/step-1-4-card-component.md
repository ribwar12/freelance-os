سلام! در این گام یکی از پرکاربردترین کامپوننت‌های فرانت‌اند یعنی **کارت‌های نئوبروتال (`Card.jsx`)** را ساختیم. در این درس یاد می‌گیری که چطور یک کانتینر انعطاف‌پذیر بنویسی که هم برای نمایش کارت‌های رنگی آمار داشبورد (KPI) و هم برای باکس‌های محتوایی استاندارد استفاده شود.

### ۱. پترن کامپوننت‌های مرکب (Compound Components):
چرا به جای یک کارت ساده، آن را به چند بخش کوچک‌تر تقسیم کردیم؟
* `Card`: کادر و حاشیه مشکی اصلی دور کل کارت.
* `CardHeader`: بخش بالایی کارت.
* `CardTitle`: فونت درشت و برجسته برای تیتر کارت.
* `CardDescription`: توضیحات خاکستری کوچک زیر تیتر.
* `CardContent`: محتوای اصلی و داده‌ها.
* `CardFooter`: بخش پایینی برای قرار دادن دکمه‌ها.

**مزیت بزرگ:**
تو به عنوان توسعه‌دهنده کاملاً آزاد هستی! هر وقت خواستی می‌توانی فقط از `Card` به تنهایی استفاده کنی (مثل کارت‌های ساده داشبورد)، و هر وقت خواستی فاکتور یا فرم کامل بسازی، همه بخش‌ها را مثل آجر لگو کنار هم بچینی:

```jsx
<Card>
  <CardHeader>
    <CardTitle>عنوان فاکتور</CardTitle>
  </CardHeader>
  <CardContent>
    محتوای فاکتور...
  </CardContent>
  <CardFooter>
    <Button>پرداخت</Button>
  </CardFooter>
</Card>
```

### ۲. بررسی خط‌به‌خط کدهای `src/components/ui/Card.jsx`:

```jsx
import React from 'react';

// ۱. کانتینر اصلی کارت
export function Card({
  children,
  variant = 'default',
  className = '',
  ...props
}) {
  // دیکشنری رنگ‌های استخراج‌شده از Google Stitch
  const variants = {
    default: 'bg-white',
    mint: 'bg-retro-mint',
    yellow: 'bg-retro-yellow',
    lavender: 'bg-retro-lavender',
    coral: 'bg-retro-coral',
    cream: 'bg-[#FDFBF7]',
  };

  return (
    <div
      className={`rounded-2xl border-2 border-black text-black shadow-retro overflow-hidden transition-all ${
        variants[variant] || variants.default
      } ${className}`}
      ...props
    >
      {children}
    </div>
  );
}
```

#### نحوه کار با پراپس `variant`:
* اگر بنویسی `<Card variant="mint">` ⬅️ کارت با پس‌زمینه سبز نعنایی برای نمایش درآمد ساخته می‌شود.
* اگر بنویسی `<Card variant="yellow">` ⬅️ کارت با پس‌زمینه زرد الکتریک برای نمایش مطالبات معوق ساخته می‌شود.
* اگر بنویسی `<Card variant="lavender">` ⬅️ کارت یاسی برای پروژه‌ها ساخته می‌شود.
* حاشیه ضخیم ۲ پیکسلی مشکی (`border-2 border-black`) و سایه سخت ۴ پیکسلی (`shadow-retro`) به صورت خودکار روی همه کارت‌ها اعمال می‌شود.
