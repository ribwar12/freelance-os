# 📘 درس ۲: پیشخوان و داشبورد تحلیلی نئوبروتالیسم (Dashboard Overview)

<div dir="rtl">

در این درس یاد می‌گیری که چطور صفحه پیشخوان اصلی نرم‌افزار را با معماری نئوبروتالیسم، زبان فارسی، جهت‌گیری راست به چپ (RTL) و اتصال به سرور استیت با **React Query** پیاده‌سازی کنی.

---

### ۱. ساختار بصری و چیدمان المان‌ها:

#### الف) بنر خوش‌آمدگویی بالا (Hero Greeting):
* این بخش شامل نام کاربر، نشان فعال بودن اسپرینت جاری، فیلتر بازه زمانی ماهانه (اسفند ۱۴۰۴) و دکمه دسترسی سریع به «صدور فاکتور جدید» است.
* حاشیه ضخیم ۲ پیکسلی مشکی به همراه سایه سخت ۴ پیکسلی، حس یک تابلوی اعلانات فیزیکی را به کاربر می‌دهد.

#### ب) کارت‌های ۴ گانه شاخص‌های عملکرد (KPI Metrics Grid):
چهار کارت رنگی با تم‌های نئوبروتال برای تفکیک ذهنی کاربر طراحی شده‌اند:
1. **درآمد وصول شده (سبز نعنایی):** نمایش مجموع مبالغ فاکتورهای تسویه شده.
2. **مطالبات در انتظار وصول (زرد الکتریک):** نمایش مبالغ فاکتورهای معوق یا منتظر پرداخت همراه با آیکون ساعت شنی.
3. **پایپ‌لاین پروژه‌های استودیو (یاسی):** نمایش تعداد پروژه‌های فعال و اسپرینت‌ها.
4. **فهرست مشتریان (صورتی مرجانی):** نمایش تعداد مشتریان طرف حساب.

---

### ۲. اتصال به داده‌های زنده سرور با React Query:

به جای استفاده از داده‌های هاردکد، مبالغ به صورت داینامیک از هوک‌های ری‌اکت کوئری محاسبه می‌شوند:

```tsx
const { data: invoices = [] } = useInvoices();
const { data: projects = [] } = useProjects();
const { data: clients = [] } = useClients();

// فیلتر و محاسبه آنی مبالغ در فرانت‌اند
const paidInvoices = invoices.filter((i) => i.status === 'paid');
const totalPaidRevenue = paidInvoices.reduce((sum, i) => sum + i.total_amount, 0);

const pendingInvoices = invoices.filter((i) => i.status === 'pending');
const totalPendingAmount = pendingInvoices.reduce((sum, i) => sum + i.total_amount, 0);
```

**نکته فنی مهم:**
به محض اینکه وضعیت فاکتوری از طریق دکمه سریع (CheckCircle) به «پرداخت شده» تغییر کند، هوک `useUpdateInvoiceStatus` کش کوئری فاکتورها را Invalidate کرده و هم کارت درآمد و هم جدول زیرین آن به طور خودکار و بدون نیاز به رفرش صفحه به‌روز می‌شوند.

---

### ۳. جدول فاکتورهای اخیر و نوارهای پیشرفت پروژه‌ها:
* **جدول:** فاکتورها را همراه با نشان‌های وضعیت رنگی (`PAID`، `PENDING`، `OVERDUE`، `DRAFT`) با فونت monospace نمایش می‌دهد.
* **پروژه‌ها:** هر پروژه دارای یک نوار پیشرفت راه‌راه (Chunky Progress Bar) با ضخامت بالا و حاشیه مشکی است که درصد پیشرفت اسپرینت را به شکل بصری نشان می‌دهد.

---

### ۴. سوال طلایی مصاحبه کاری برای صفحه داشبورد:
> **مصاحبه‌کننده:** «چطور مطمئن شدی که محاسبات ریاضی داشبورد (مثل جمع کل درآمد یا تعداد فاکتورها) باعث کندی اپلیکیشن نمی‌شوند؟»
> **پاسخ تو:** «در کامپوننت داشبورد، آرایه‌های فاکتورها در حافظه کش React Query نگهداری می‌شوند و محاسبات ساده `filter` و `reduce` با پیچیدگی زمانی O(N) روی آرایه در کسری از میلی‌ثانیه انجام می‌شوند. در صورت بزرگ شدن داده‌ها در اسکیل میلیونی، این جمع‌ها با مکانیزم aggregation در سطح دیتابیس Supabase انجام شده و فقط خروجی خلاصه آماری به فرانت‌اند فرستاده می‌شود.»
