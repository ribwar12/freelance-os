## ۱. هدف و فلسفه این گام

هر قرارداد حرفه‌ای نیازمند تصریح شرایط پرداخت، دیرکرد و کانال واریز دستمزد است. در این گام:
1. **کارت شماره ۳ فرم سازنده فاکتور** بر اساس زبان بصری نئوبروتالیسم (حاشیه ۳ پیکسلی، بج بنفش لواندر و تفکیک دو ستونه) پیاده‌سازی شد.
2. **شروط حقوقی و یادداشت‌های کارفرما (Client Notes & Terms):**
   - فیلد متنی چندخطی برای ذکر موعد پرداخت (۲۱ روزه)، اولویت واریز شبا، جریمه دیرکرد ماهانه و شرط انتقال مالکیت کدهای پروژه پس از تسویه کامل.
   - شمارنده زنده کاراکترها به خط فارسی (`toPersianDigits`).
3. **باکس رسمی حساب بانکی (Official Bank Details Box):**
   - پس‌زمینه سبز نعنایی رترو با برچسب اصالت شاپرک (`حساب تاییدشده`).
   - نام بانک عامل: `بانک سامان — حساب جاری عملیاتی استودیو`.
   - نام صاحب حساب: `الکس مرادی (مدیر اجرایی FreelanceOS)`.
4. **دکمه‌های کپی فوری کلیپ‌بورد (Copy to Clipboard):**
   - **شماره شبا (IBAN/SHEBA):** `IR82 0560 0840 8000 0124 5592 01` همراه با دکمه کپی فوری با قابلیت انتخاب متن.
   - **شماره کارت بانکی (Card Number):** `6219 8610 4421 9083` همراه با دکمه کپی فوری.
   - دارای فیدبک بصری تغییر دکمه به «کپی شد! ✓» با رنگ نعنایی و ارسال نوتیفیکیشن در بالای صفحه.

## ۲. توابع و کدهای کلیدی

استفاده از Web API استاندارد مرورگر `navigator.clipboard.writeText`:

```javascript
const handleCopy = (text, type, label) => {
  if (navigator?.clipboard?.writeText) {
    navigator.clipboard.writeText(text);
    setCopiedType(type);
    if (onCopyFeedback) {
      onCopyFeedback(`${label} با موفقیت در کلیپ‌بورد کپی شد! 📋`);
    }
    setTimeout(() => setCopiedType(null), 2500);
  }
};
```
