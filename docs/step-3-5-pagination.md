## ۱. هدف و فلسفه این گام

در سامانه‌های حرفه‌ای، نمایش یک‌باره صدها ردیف در جدول باعث افت سرعت مرورگر و سردرگمی کاربر می‌شود. در این گام:
1. **نوار صفحه‌بندی قطور نئوبروتال (Tactile Chunky Pagination):** در بخش پایینی کارت ماتریس فاکتورها مستقر شد.
2. **شمارنده فارسی و هوشمند اقلام:** مثلاً `نمایش ۱ تا ۵ از ۱۳ فاکتور`.
3. **نشانگر تعداد اقلام انتخاب‌شده:** با تغییر لحظه‌ای انتخاب چک‌باکس‌ها، بج زرد رنگ تعداد را نمایش می‌دهد.
4. **انتخاب‌گر داینامیک اندازه صفحه (Page Size Selector):** گزینه‌های ۵، ۱۰، ۲۰ و ۵۰ ردیف در صفحه.
5. **ناوبری صفحات:** دکمه‌های قبلی، بعدی و شماره صفحات با هایلایت مشکی قطور روی صفحه جاری.
6. **داک میانبرهای کیبورد (Shortcuts Dock):** پشتیبانی از فشردن کلیدهای `N` (فاکتور جدید)، `F` (فیلتر)، `/` (جستجوی زنده) و `E` (خروجی اکسل).

## ۲. منطق ریاضی و محاسباتی صفحه‌بندی

در فایل `App.jsx`، صفحه‌بندی بر روی آرایه فیلترشده فاکتورها (`filteredInvoices`) اعمال می‌شود:

```javascript
// ۱. محاسبه تعداد کل صفحات
const totalPages = Math.max(1, Math.ceil(filteredInvoices.length / itemsPerPage));

// ۲. جلوگیری از ماندن روی صفحه‌ای که پس از فیلتر دیگر وجود ندارد
const safeCurrentPage = Math.min(currentPage, totalPages);

// ۳. محاسبه ایندکس شروع و برش آرایه
const startIndex = (safeCurrentPage - 1) * itemsPerPage;
const paginatedInvoices = filteredInvoices.slice(startIndex, startIndex + itemsPerPage);
```

## ۳. بومی‌سازی ارقام به خط فارسی

تابع کمکی `toPersianDigits` اعداد را به شکل استاندارد فارسی تبدیل می‌کند تا با تایپوگرافی مونو و فارسی واسط کاربری همگام شود:

```javascript
export function toPersianDigits(num) {
  if (num === null || num === undefined) return '';
  const farsiDigits = ['۰', '۱', '۲', '۳', '۴', '۵', '۶', '۷', '۸', '۹'];
  return num.toString().replace(/\d/g, (d) => farsiDigits[d]);
}
```

## ۴. استایل نئوبروتال دکمه‌های صفحه‌بندی

مطابق با دیزاین استیچ:
- **دکمه صفحه فعال:** `bg-black text-white shadow-[2px_2px_0_0_#000000]`
- **دکمه‌های سایر صفحات:** `bg-white text-black border-2 border-black shadow-[2px_2px_0_0_#000000] hover:bg-retro-yellow active:translate-x-0.5 active:translate-y-0.5`
- **دکمه‌های غیرفعال (Disabled):** `bg-neutral-200 text-neutral-400 border-neutral-300 shadow-none cursor-not-allowed`

## ۵. میانبرهای کیبورد سراسری (Keyboard Shortcuts)

یک `useEffect` در `App.jsx` رویدادهای فشردن کلید را ثبت می‌کند، مگر این‌که فوکوس کاربر داخل یک فیلد فرم (`input`, `textarea`, `select`) باشد:

- **فشردن `N`:** آماده‌سازی صدور فاکتور جدید.
- **فشردن `F`:** هدایت و تمرکز روی فیلترها.
- **فشردن `/`:** فوکوس خودکار روی اینپوت جستجوی زنده.
- **فشردن `E`:** تولید خروجی اکسل / CSV.
