# 📘 درس ۱-۱: ستاپ پروژه ری‌اکت جاوااسکریپت خالص (بدون تایپ‌اسکریپت)

<div dir="rtl">

سلام! از اینجا مسیر جدید و قدم‌به‌قدم ما شروع می‌شود. در این گام، تمام پیچیدگی‌های تایپ‌اسکریپت (TypeScript) را کنار گذاشتیم تا کدها **دقیقاً مثل مباحث دوره‌ای که می‌گذرانی (Pure JavaScript / React JSX)** ساده، خوانا و قابل درک باشند.

---

### ۱. چرا حذف تایپ‌اسکریپت تصمیم هوشمندانه‌ای بود؟
تایپ‌اسکریپت ابزار فوق‌العاده‌ای است، اما برای کسی که هنوز در حال گذراندن دوره فرانت است، نوشتن اینترفیس‌ها، تایپ‌های ژنریک `<T>` و ارورهای سخت‌گیرانه کامپایلر، بار ذهنی مضاعف ایجاد می‌کند. با بازگشت به **جاوااسکریپت خالص (`.jsx`)**:
* حجم کدها نصف شد.
* دیگر با کلمات پیچیده‌ای مثل `interface`، `type` و ارورهای اعصاب‌خردکن تایپ سروکار نداری.
* کدها دقیقاً شبیه همان چیزی است که استادت در دوره آموزش می‌دهد.

---

### ۲. در گام ۱-۱ چه فایل‌هایی دستخوش تغییر شدند؟

1. **حذف فایل‌های کانفیگ تایپ‌اسکریپت:** تمام فایل‌های `tsconfig.json`، `tsconfig.node.json` و فایل‌های کش مربوط به آن حذف شدند.
2. **فایل `package.json`:** دستور بیلد از `tsc && vite build` به یک دستور ساده و سریع `vite build` تبدیل شد.
3. **فایل `vite.config.js`:** به جاوااسکریپت بازنویسی شد تا بتوانیم در کامپوننت‌ها از علامت `@` به عنوان آدرس میانبر پوشه `src` استفاده کنیم.
4. **فایل `index.html`:** ارجاع اسکریپت ریشه از `main.tsx` به `main.jsx` تغییر یافت.
5. **فایل‌های ریشه برنامه (`main.jsx` و `App.jsx`):** با کدهای ساده و تمیز ری‌اکت ایجاد شدند.

---

### ۳. بررسی خط‌به‌خط کدهای ساخته‌شده:

#### الف) فایل `src/main.jsx` (نقطه ورود برنامه):
```jsx
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App';
import './index.css';

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);
```
* **خط ۱ و ۲:** کتابخانه ری‌اکت و ابزار `ReactDOM` را وارد می‌کنیم.
* **خط ۳:** کامپوننت مادر یعنی `App` را فراخوانی می‌کنیم.
* **خط ۴:** فایل استایل‌های سراسری را لود می‌کنیم.
* **خط ۶ تا ۱۰:** متد `createRoot` المنت `<div id="root"></div>` را از فایل HTML برمی‌دارد و ری‌اکت را روی آن سوار می‌کند.

#### ب) فایل `src/App.jsx` (کامپوننت پایه تست):
```jsx
import React from 'react';

export default function App() {
  return (
    <div className="min-h-screen bg-[#FDFBF7] flex items-center justify-center p-4">
      <div className="rounded-2xl border-2 border-black bg-white p-8 shadow-[4px_4px_0px_#000] max-w-md w-full text-center space-y-4">
        ...
      </div>
    </div>
  );
}
```
* این کامپوننت فعلاً به عنوان یک کارت تستی ساده کار می‌کند تا مطمئن شویم پروژه بدون تایپ‌اسکریپت با موفقیت بیلد می‌شود.
