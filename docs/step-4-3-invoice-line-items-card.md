## ۱. هدف و فلسفه این گام

قلب مالی هر فاکتور، جدول خدمات و اقلام تحویلی است. در این گام:
1. **کارت شماره ۲ فرم سازنده فاکتور** بر اساس دیزاین سیستم نئوبروتالیسم (حاشیه ۳ پیکسلی مشکی، بج نعنایی و هدر قطور تفکیک‌شده) ایجاد گردید.
2. **جدول تعاملی اقلام (Line Items Table):**
   - ستون `#`: شماره دو رقمی ردیف با فونت مونو (`۰۱`، `۰۲`، ...).
   - ستون **شرح خدمت و دامنه کار (Scope):** دو اینپوت متنی جداگانه برای عنوان اصلی و توضیحات تکمیلی.
   - ستون **ساعت / تعداد کارکرد:** اینپوت عددی با کنترل واحد (ساعت یا پکیج).
   - ستون **نرخ واحد:** اینپوت عددی با گام‌های ۵۰ هزار تومانی و پیش‌نمایش ۳ رقم ۳ رقم فارسی زیر فیلد.
   - ستون **جمع کل سطر:** محاسبه بلادرنگ و اتوماتیک (`ساعت × نرخ`).
   - ستون **عملیات:** دکمه سطل زباله نئوبروتال جهت حذف سطر (با هاور رنگ مرجانی).
3. **دکمه‌های اقدام زیر جدول:**
   - **`+ افزودن سطر خدمات جدید`:** ایجاد یک ردیف نو با مقادیر پیش‌فرض در استیت.
   - **`دریافت کارکرد ثبت‌شده از تایم‌شیت`:** دکمه با خط‌چین نئوبروتال برای ری‌ست و بارگذاری مجدد ساعات کاری پروژه‌ها.
4. **اتصال مستقیم به سایدبار صندوق حسابداری زنده (Live Cash Register):**
   - هر تغییری در ساعت یا نرخ هر یک از سطرها، بلافاصله مبالغ **جمع ناخالص (Gross Subtotal)**، **تخفیف ۱۰٪**، **ارزش افزوده ۱۰٪ (VAT)** و **مبلغ نهایی قابل پرداخت (Total Due)** را در سایدبار چسبان سمت چپ لحظه‌ای محاسبه و به‌روز می‌کند!

## ۲. توابع ریاضی و ساختار داده‌ها

هر سطر به شکل یک آبجکت استاندارد در استیت `lineItems` ذخیره می‌شود:

```javascript
{
  id: 'item-1',
  title: 'ممیزی دیزاین سیستم و معماری توکن‌ها',
  description: 'بازبینی کامپوننت لایبرری در Figma و ساختار توکن‌های چندسکویی',
  qty: 40,
  unit: 'ساعت',
  rate: 650000,
}
```

محاسبات مالی بلادرنگ در `App.jsx`:
```javascript
// جمع ناخالص کل سطرها
const grossSubtotal = lineItems.reduce(
  (sum, item) => sum + (Number(item.qty) || 0) * (Number(item.rate) || 0),
  0
);

// تخفیف همکاری ۱۰ درصدی
const discountPercent = 10;
const discountAmount = Math.round((grossSubtotal * discountPercent) / 100);
const netAfterDiscount = grossSubtotal - discountAmount;

// مالیات قانونی بر ارزش افزوده ۱۰ درصدی
const vatTaxAmount = Math.round((netAfterDiscount * 10) / 100);

// مبلغ نهایی قابل پرداخت
const finalTotalAmount = netAfterDiscount + vatTaxAmount;
```
