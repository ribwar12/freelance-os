## 📖 معرفی پروژه

**FreelanceOS** یک وب‌اپلیکیشن تجاری کامل و آماده ارائه در نمایشگاه‌های تخصصی فناوری و کار است. این نرم‌افزار با تلفیق زبان طراحی **نئوبروتالیسم (Neo-brutalism)** — خطوط مشکی برجسته (`3px solid #000`)، سایه‌های سخت زاویه‌دار (`shadow-[4px_4px_0_0_#000]`)، پالت رنگ‌های پاستلی رترو و فونت‌های مدرن فارسی — تجربه‌ای متمایز، پویا و بی‌نهایت سریع برای مدیریت کسب‌وکار فریلنسینگ خلق کرده است.

این سامانه به صورت اختصاصی با قوانین پولی و مالیاتی ایران (تومان، شماره شبا، شناسه ملی، کد اقتصادی، مالیات بر ارزش افزوده ۱۰٪ ماده ۱۶۹ م.م و فرمت رسمی چاپ A4) منطبق شده است.

## ✨ امکانات و ماژول‌های سیستم

### ۱. پیشخوان اجرایی و مرکز فرماندهی (Executive Dashboard)
- **کارت‌های شاخص عملکرد (KPIs):** درآمد کل وصول‌شده، مطالبات معوق، پروژه‌های جاری و وضعیت باشگاه مشتریان.
- **تغییر دوره محاسباتی پویا:** امکان سوییچ زنده بین «ماه جاری»، «ماه قبل»، «پاییز ۱۴۰۵» و «سالانه» با انیمیشن‌های عددی.
- **ویجت پروژه‌های فعال و اسپرینت‌ها:** رصد لحظه‌ای پیشرفت، ضرب‌الاجل تحویل و فازبندی قراردادها.
- **جدول فاکتورهای اخیر:** دسترسی سریع به تراکنش‌های اخیر و میانبرهای عملیاتی.

### ۲. دایرکتوری و مدیریت جامع صورت‌حساب‌ها (Invoices Directory)
- **فیلترهای چندگانه بلادرنگ:** فیلتر بر مبنای وضعیت (همه، تسویه شده، در انتظار واریز، سررسید گذشته، پیش‌نویس)، کارفرما، بازه زمانی و جستجوی متنی لحظه‌ای.
- **عملیات گروهی و تکی (Bulk Actions):** قابلیت انتخاب چندگانه سطرها با چک‌باکس، تسویه دسته‌جمعی، حذف و اکسپورت داده.
- **صفحه‌بندی هوشمند نئوبروتال:** کنترل تعداد اقلام در هر صفحه (۵، ۱۰، ۲۰ تایی)، دکمه‌های پرش به صفحات و نمایش شناور وضعیت.
- **کلیدهای میانبر صنعتی صفحه‌کلید (Keyboard Shortcuts):**
  - `N` / `n`: صدور فاکتور جدید
  - `/`: فوکوس مستقیم روی نوار جستجو
  - `Escape`: پاک‌سازی فیلترها و خروج از مودال‌ها

### ۳. سازنده تعاملی فاکتور (Interactive Invoice Builder)
- **فرم متاداده فاکتور:** انتخاب داینامیک کارفرما، عنوان پروژه، شماره قرارداد/سفارش (PO Ref)، تاریخ صدور و سررسید خورشیدی.
- **جدول داینامیک خدمات و اقلام تحویلی:** افزودن سطر، تعیین ساعت کارکرد/تعداد، نرخ واحد، محاسبه اتوماتیک جمع هر سطر و امکان همگام‌سازی با تایم‌شیت.
- **یادداشت‌های حقوقی و حساب بانکی:** درج خودکار شماره شبا ۲۴ رقمی، شماره کارت بانکی و متن قانونی الزام تسویه.
- **صندوق دریافت زنده (Live Receipt Sidebar):** کارت شناور فاکتور با محاسبه آنی ساب‌توتال ناخالص، اعمال درصد تخفیف، محاسبه ارزش افزوده ۱۰٪ (VAT) و نمایش جمع کل نهایی به تومان و ریال.

### ۴. برگه رسمی استاندارد A4 و موتور چاپ و PDF (Official Tax Invoice)
- **تطابق با فرم استاندارد ماده ۱۶۹ م.م:** هدر رسمی استودیو، کد ثبت، کد اقتصادی، شماره پرونده مالیاتی.
- **جدول مشخصات فروشنده و خریدار:** نمایش دپارتمان محصول، شناسه ملی، کد اقتصادی ۱۲ رقمی، کد پستی و آدرس.
- **جدول مهندسی اقلام با فونت‌های مونو:** تفکیک دقیق شرح خدمات، مشخصات فنی، مقدار و قیمت.
- **باکس تسویه بانکی و کپی تعاملی:** کلیک مستقیم برای کپی سریع شماره شبا و شماره کارت بانکی در کلیپ‌بورد.
- **ماتریس QR و اصالت رمزنگاری:** شبیه‌سازی ماتریس ۲ بعدی QR، کد هش رمزنگاری سند (`SHA-256: 7f8a9e4b21c0b784`) و تاییدیه همگام‌سازی مالیاتی (`STAMPED • IR-MOF-SYNC`).
- **امضای دیجیتال و مهر برجسته استودیو:** امضای لاتین دیجیتال معمار ارشد و مهر برجسته دورنگ قرمز استودیو با زاویه چرخش طبیعی منفی ۸ درجه.
- **بهینه‌سازی کامل CSS Print:** خروجی دقیق سایز کاغذ A4 پرتره با حاشیه‌های استاندارد، حذف اجزای ناوبری در چاپ (`print:hidden`) و جلوگیری از شکستگی سطرها (`break-inside: avoid`).

### ۵. سوئیت مودال‌های عملیاتی و مدیریت کارفرمایان (Dialog Suite & Clients Matrix)
- **مودال ثبت کارفرمای جدید (`AddClientModal`):** ورود اطلاعات کامل شرکتی با استعلام شناسه ملی و تزریق آنی به گزینه‌های فاکتور.
- **مودال تعریف اسپرینت (`AddProjectModal`):** بودجه‌بندی اسپرینت، اتصال به کارفرما و تعیین مدل مالی.
- **صفحه کارفرمایان (`/clients`):** ماتریس کارت‌های کارفرمایان رسمی و صدور تک‌کلیک فاکتور.
- **صفحه پروژه‌ها (`/projects`):** تقویم اسپرینت‌ها، درصد پیشرفت و بودجه‌های مصوب.
- **صفحه گزارشات (`/reports`):** گزارش فصلی ارزش افزوده (VAT)، توزیع درگاه‌های بانکی و دانلود اکسل/CSV.

## 🏗️ معماری نرم‌افزار و مدیریت استیت (State Architecture)

### چرا استیت بومی ری‌اکت (React Pure Reactive State)؟
در این پروژه، به جای تحمیل کتابخانه‌های سنگین و پیچیده مانند Redux Toolkit (که حجم باندل را ۴۰+ کیلوبایت افزایش می‌دهند و کدهای تکراری Action/Reducer ایجاد می‌کنند)، از **معماری تک‌منبعی مدرن ری‌اکت (Single Source of Truth / Lifted State)** استفاده شده است:

1. **عملکرد فوق‌العاده و حجم سبک:** کل حجم باندل نهایی پروداکشن تنها **۳۵۵ کیلوبایت** (فشرده‌شده: **۹۱ کیلوبایت**) با زمان کامپایل **۲.۱ ثانیه** است.
2. **پیش‌بینی‌پذیری و جریان یک‌طرفه داده (Unidirectional Data Flow):** تمامی داده‌های فاکتورها، کارفرمایان و پروژه‌ها در لایه ریشه مدیریت شده و رویدادها با Callback‌های صریح به سمت بالا هدایت می‌شوند.
3. **عدم وابستگی به ابزارهای جانبی (Zero-bloat):** کد پروژه ۱۰۰٪ خالص، بدون فایل‌های بدون استفاده و بدون پیچیدگی‌های ابزاری اجرا می‌شود.
4. **قابلیت ارتقا در آینده:** در صورت نیاز به افزودن قابلیت‌های چندکاربره ابری یا همگام‌سازی توزیع‌شده آفلاین، معماری ماژولار کامپوننت‌ها به سادگی به **Zustand** یا **Redux Toolkit** متصل خواهد شد.

## 🚀 استقرار روی ورسـل (Vercel Deployment)

پروژه دارای فایل کانفیگ اختصاصی [`vercel.json`](./vercel.json) است تا تمامی مسیرهای کلاینت-ساید (مانند `/invoices` یا `/clients`) در هنگام ریفرش بدون خطای ۴۰۴ لود شوند.

### روش ۱: اتصال خودکار از گیت‌هاب (پیشنهادی)
1. وارد داشبورد [Vercel](https://vercel.com/) شوید.
2. روی دکمه **Add New Project** کلیک کنید.
3. ریپازیتوری `ribwar12/freelance-os` را انتخاب کنید.
4. فریم‌ورک به صورت خودکار `Vite` شناسایی می‌شود.
5. دکمه **Deploy** را بزنید. پروژه ظرف کمتر از ۱ دقیقه مستقر می‌شود!

### روش ۲: استقرار با Vercel CLI
```bash
# ۱. ورود به حساب کاربری
npx vercel login

# ۲. استقرار نهایی پروژه
npx vercel --prod
```

## 💻 راهنمای نصب و اجرای محلی

```bash
# ۱. کلون کردن ریپازیتوری
git clone https://github.com/ribwar12/freelance-os.git

# ۲. ورود به دایرکتوری پروژه
cd freelance-os

# ۳. نصب پکیج‌ها
npm install

# ۴. اجرای سرور توسعه محلی
npm run dev
```

سپس مرورگر خود را باز کرده و به آدرس زیر مراجعه فرمایید:
```text
http://localhost:5173
```

برای تست بیلد نهایی پروداکشن:
```bash
npm run build
npm run preview
```
